# Список изменений

## 1.5.0

🚀 **Крупное обновление!** Это не только набор новых возможностей, но и масштабная работа над стабильностью.

!!! Tip
    Поддержка Python 3.10 прекращается 31.10.2026 — вместе с окончанием её официальной поддержки Python Software Foundation.

**Добавлено:**

- Поддержка входящих голосовых сообщений с типом `MessageType.VOICE_MESSAGE` (`205`)
- Поддержка инлайн-кнопок через `InlineKeyboardMarkup`/`InlineKeyboardButton` (действия: команда, URL, сообщение, копирование). Требуется TrueConf Server 5.5.6 и клиентские приложения TrueConf для Windows, macOS и Linux версии 8.6.0, TrueConf для Android 3.3.0, TrueConf для iOS 4.2.0
- Callback-запросы для обработки нажатий на кнопки: обработчик `@router.callback_query()`, шорткаты `callback_query.edit_message(...)` и `callback_query.answer(...)`
- Кнопки с `wait_reply=True` и метод `answerCommand` временно вызывают `NotImplementedError`: функциональность поддерживается сервером TrueConf, но ожидает поддержки со стороны клиентских приложений. После её появления будет выпущен новый релиз, снимающий это ограничение
- Объект чата: поле `chat` с моделью `Chat` в `Message` и `LastMessage`
- Ответы на сообщения: во входящем сообщении-ответе появился `Message.reply_message` с содержимым исходного сообщения, на которое дан ответ
- Системные сообщения: модель `SystemMessage` и обработчик `@router.system_message()`
- Ответ с цитатой через параметр `quote` в `Message.reply()` и `Bot.send_message()`, а также свойство `Message.quote`
- Индикатор активности в чате: метод `Bot.send_chat_activity()`, перечисление `ChatActivity` и контекстный менеджер `ChatActivitySender.typing(...)`
- Ограничение размера файла, загружаемого в память, параметром `max_in_memory_download_size`
- Узел `LineBreak` в `trueconf.utils.formatting` (`<br>` для HTML, `\n` для Markdown)
- Шорткаты `message.location` для геолокации и `message.contact` для контактов (vCard-файлы и trueconf-ссылки)
- Авторизация через OAuth2 с помощью `Bot.from_oauth()` для серверов с отключённой поддержкой авторизации через логин и пароль. Требуется TrueConf Server 5.5.3+
- Новые исключения: `WSConnectionError`, `InMemoryDownloadLimitExceededError`, `FileUploadError`, `OAuthMissingScopeError`, `PasswordAuthDisabledError`
- Текстовые расшифровки кодов ошибок API (399, 400–408) в `ApiError.message()`. Коды 400–408 относятся к файлам и заменяют один общий код 310 («ошибка при отправке») — теперь понятно, что именно пошло не так при отправке
- Поле `caption_message_id` в `SendFileResponse` — ID сообщения с подписью, отправленного вместе с файлом; позволяет изменить подпись файла через `edit_message(...)`
- Кастомный `User-Agent` во всех запросах библиотеки в формате `python-trueconf-bot/<version> (Python/<version>; <OS>/<release>)`, например: `python-trueconf-bot/1.5.0 (Python/3.12.4; Darwin/24.0.0)`

**Изменено:**

- Узел `Underline` в `trueconf.utils.formatting` теперь рендерится и в Markdown (`__текст__`) — ранее подчёркивание работало только в HTML-разметке
- Скачивание файлов: параметр `file_path` задаёт точный путь, родительские каталоги создаются автоматически
- Параметр `mimetype` переименован в `mime_type`
- Поведение `ws_max_retries`/`ws_max_delay`: после исчерпания попыток подключение завершается с `WSConnectionError`
- Завершение бота ожидает запущенные обработчики и закрывает WebSocket-транспорт; в `shutdown()` добавлен параметр `timeout`
- HTTP-клиент переведён с `httpx` на `httpx2`

**Исправлено:**

- Разбор системных сообщений в истории чата и ответах API
- Ошибки загрузки файлов: вызывающий код получает `FileUploadError` с исходной причиной
- Бесконечное переподключение WebSocket после исчерпания лимита попыток
- При остановке бота WebSocket-соединение не закрывалось — теперь сессия корректно закрывает подключённый сокет
- URL скачивания и токены больше не попадают в лог целиком: у URL удаляется query-строка (`https://server/.../files/download?token=...` → `https://server/.../files/download`), а токен в debug-логах обрезается до последних 30 символов
- Получение токена в `Bot.from_credentials()` теперь учитывает параметры `https` и `web_port` — ранее токен запрашивался по https:443, даже если сервер работает по http или на нестандартном порту

**Устарело:**

- Свойство `Message.chat_id` — используйте `message.chat.chat_id`
- Параметр `dest_path` — используйте `file_path` (удаление в версии 2.0)
- Параметр `mimetype` — используйте `mime_type`

## 1.4.0

**Добавлено:**

- **FSM (Finite State Machine)** — механизм конечных автоматов состояний. Позволяет реализовать пошаговые диалоги: анкеты, формы, мастер-настройки. 
Состояния объявляются декларативно через `StatesGroup`/`State`, данные хранятся в `FSMContext`. 
Поддерживает вложенные группы, несколько стратегий хранения и фильтрацию по состоянию через `StateFilter`. Подробнее: [FSM](learn/fsm.md).
- **Middleware** — прослойка для обработки событий до и после хендлеров. 
Позволяет логировать, блокировать, проверять доступ и модифицировать данные. 
Поддерживает два типа: outer (до фильтров) и inner (после фильтров). Подробнее: [Middleware](learn/middleware.md).
- **Параметр `skip_self_messages`** в `Bot()`. 
По умолчанию `True` — бот автоматически игнорирует сообщения, отправленные самим собой. 
Отключается параметром `skip_self_messages=False`.
- Поле `Message.reply_message` с полным сообщением, на которое был отправлен ответ.
- Модель `SystemMessage` для системных Envelope в live-потоке и истории чата, а также обработчик
  `@router.system_message()`.

**Исправлено:**

- Поле `for_all` нотификации очистки истории теперь сохраняет серверный тип `bool`.

## 1.3.0

**Добавлено:**

- Механизм health-check для отслеживания состояния подключения бота:
    - push-модель через callback `Bot(on_health_check=func_callback)`, который вызывается при изменении статуса подключения;
    - pull-модель через метод `bot.health_check()`, который возвращает текущее состояние бота. 
    - статусы `connected`, `authorized` и `disconnected`.
- Поддержка `bot.me_id` для хранения идентификатора авторизованного бота.
- Шорткат `message.mention`, который возвращает `True`, если в сообщении упомянут текущий бот или используется `@all`.
- Модуль форматирования `trueconf.utils.formatting` для удобного построения HTML/Markdown-сообщений через классы: `Text`, `Bold`, `Italic`, `Underline`, `Strikethrough`, `Link`, `Mention`, `AllMention`.
- Зависимость `truststore` для работы с системным хранилищем доверенных сертификатов.
- Тип `SSLVerify` для унифицированной типизации параметра `verify_ssl`: `bool | str | ssl.SSLContext`.
- Свойство `bot.me_chat` как новое имя для получения `chat_id` чата "Избранное".

**Изменено:**

- Обновлена логика работы `verify_ssl`:
    - `verify_ssl=True` использует системное хранилище доверенных сертификатов через `truststore`;
    - `verify_ssl=False` отключает проверку сертификата;
    - `verify_ssl="/path/to/ca.pem"` использует пользовательский CA bundle;
    - `verify_ssl=ssl.SSLContext(...)` использует переданный SSL-контекст.
- Обновлена SSL-логика для WebSocket-подключений: теперь используется единый `self.ssl_context`, созданный через `build_ssl_context(...)`.
- Обновлено логирование при инициализации бота: теперь в лог выводится человекочитаемая информация о SSL-контексте.

**Исправлено:**

- Обработка неполной цепочки сертификатов заканчивалась неудачей. Теперь цепочка сертификатов проверяется успешно за счёт возможности использовать системное хранилище через `truststore` или передавать собственный SSL-контекст.

**Устарело:**

- Асинхронное свойство `bot.me`, которое возвращает `chat_id` чата "Избранное", помечено как устаревшее. Используйте `await bot.me_chat` вместо него.

**Документация:**

- Интегрирован ИИ-ассистент (виджет чата Context7): интерактивный помощник для консультаций по коду и документации.
- Добавлен новый раздел документации **Отправка сообщений** с описанием:
    - получения `chat_id`;
    - отправки текстовых сообщений через `bot.send_message(...)`;
    - отправки ответа через `reply_message_id`;
    - пересылки сообщений через `bot.forward_message(...)`;
    - форматирования текста через `trueconf.utils.formatting`;
    - ограничения длины сообщения в 4096 символов и использования `safe_split_text(...)`.
- Добавлено описание health-check в документацию:
    - push-модель через callback;
    - pull-модель через `bot.health_check()`;
    - пример совместного использования с HTTP health endpoint.
- Добавлены и обновлены docstring для модуля форматирования, `Message.mention`, `verify_ssl` и health-check API.
- Добавлены новые разделы: **Шорткаты**, **Ограничения**, **Formatting**, **Exceptions**.

## 1.2.0

**Добавлено:**

- Добавлена поддержка TrueConf Server 5.5.3, включая:
    - изменение названия чата с помощью `bot.edit_chat_title(...)`;
    - изменение аватара чата с помощью `bot.edit_chat_avatar(...)`;
    - очистку истории чата с помощью `bot.clear_chat_history(...)`;
    - получение лимитов файлового хранилища с помощью `bot.get_file_info_upload_limits(...)`;
    - новый подход к передаче файлов, при котором параметр `file_name` теперь обязателен для `FSInputFile(...)` и других методов загрузки файлов.
- Добавлено кэширование настроек лимитов файлового хранилища. Эти настройки теперь используются для предварительной проверки перед загрузкой, и библиотека вызывает исключение, если файл не соответствует заданным ограничениям.
- Добавлены библиотеки `python-magic` и `filetype` для более надежного определения типа файла по magic numbers (байтовым сигнатурам).
- Добавлено автоматическое добавление расширения файла, если оно отсутствует в имени файла.
- Улучшена стабильность WebSocket-соединения: добавлены экспоненциальная задержка и настраиваемая стратегия повторных подключений. Теперь можно управлять максимальным количеством попыток повторного подключения через `ws_max_retries` и максимальной задержкой между попытками через `ws_max_delay` ([#6](https://github.com/TrueConf/python-trueconf-bot/issues/6)).
- Добавлена проверка версии TrueConf Server. Теперь библиотека вызывает `RuntimeError` с инструкциями по обновлению, если обнаружена несовместимая версия сервера.
- Добавлена утилита `safe_split_text` для безопасного разделения длинных сообщений, превышающих 4096 символов, на части длиной до 4096 символов. Это особенно полезно для ИИ-агентов, которые генерируют длинные ответы.
- Добавлены сборки документации, удобные для ИИ: `llms.txt` и `llms-full.txt`.
- Добавлено и расширено логирование.

**Исправлено:**

- Исправлена проблема с отправкой стикеров в TrueConf Server 5.5.3+.
- Исправлена проблема [#7](https://github.com/TrueConf/python-trueconf-bot/issues/7).
- Исправлены различные мелкие ошибки и внесены общие улучшения.

**Устарело:**

- Параметры `filename` и `mimetype` теперь помечены как устаревшие.
- Перейдите на новые имена параметров в формате `snake_case`, так как старые параметры будут удалены в будущих версиях.
